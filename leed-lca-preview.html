Bechtel 의 LEED 자료 (운영 에너지 + 구조 재사용) 가 Grimes popup 안에 들어간 모습. Engineer 모드와 Public 모드 각각에서 어떻게 보이는지. 실제 라이브 화면은 grimes-campus-map-arcgis.html 에서 Grimes 마커 클릭 → 우상단 토글로 모드 전환.

01 Engineer 모드 우측 SCADA 패널 안
ENGINEER

어디서: Grimes 마커 클릭 → 우상단 모드 토글 → 우측에 docked 되는 좁은 검정 패널.

누구를 위한 화면: facility manager · 연구원 — 정확한 숫자와 비교가 필요한 사람.

표시되는 LEED 패널 2개:

  • Design Intent vs Actual — 법규 / 설계 / 실제 라이브 3-bar 비교, gap % 가 우상단
  • Material Reuse — element 별 reuse %, 전체 % 가 우상단

두 패널 모두 row hover 하면 정확한 수치 (kWh/yr, sqft 등) 가 툴팁으로.
